# Kijitama Prompt Generator（プロトタイプ）

[Kijitama 公式サイト](https://note.com/kijitama)

本ツール独自のコードはMIT Licenseで配布します。著作権表示と許諾条件の全文は [LICENSE.txt](LICENSE.txt) に収録しています。

PowerShell 7とWPFで作成した、Windows用の画像・プロンプト生成ツールです。

## 起動

起動用exeは毎回 `app/Launcher/launcher.json` を読み込みます。`script` に起動したいPowerShellスクリプトのパスを指定してください。相対パスの基準はexeのあるフォルダーです。初期値は `app/Start.ps1` です。設定を保存すると次回の起動から反映されます。

1. **`Kijitama Prompt Generator.exe`** をダブルクリックします。黒いコンソール画面を開かずにGUIを起動します。
2. 右上の「設定」で、「参照…」で生成結果の保存先を選び、**Codex CLIのcodex.exe** を指定して、「保存」を押します。「自動検出」も使えます。
3. 使いたい機能のタブを選び、内容を入力して生成ボタンを押します。

PowerShell 7が必要です。Windows標準のWindows PowerShell 5.1では動きません。設定ファイルは`app/settings.json` に保存するため、書き込み可能なフォルダーに置いてください。

exeは起動用です。`app` フォルダーも一緒に配置してください。通常はexeから起動し、旧 `起動.cmd` は使用しません。起動用exeのソースと再ビルド用スクリプトは `app/Launcher` にあります。

## 3つの機能

| タブ | 入力 | 結果 |
| --- | --- | --- |
| ① プロンプト → 画像 | 画像生成用のプロンプト | 生成画像1枚・画面プレビュー |
| ② 言葉 → プロンプト | 自由な言葉で書いた希望 | 日本語の画像生成プロンプト |
| ③ 画像 → プロンプト | PC内の画像パス、または画像そのもののHTTP/HTTPS URL | 見た目を再現するための日本語プロンプト |

プロンプトの結果は「プロンプトをコピー」でコピーできます。「このプロンプトで画像を作る」で①へ転記し、確認してから画像を生成できます。

③の追加希望は任意です。元の画像に使われたプロンプトを復元するものではありません。PNG、JPEG、BMP、GIF、TIFFなどWindowsの画像デコーダーで読める形式に対応し、入力は20MB・4,000万画素までです。GIFなどの複数フレーム画像は先頭フレームを使います。WebPの対応はPCのデコーダー環境に依存するため、PNG/JPEGを推奨します。

URLにはWebページのURLではなく、画像ファイルを直接返すURLを指定してください。ログインが必要なサイトの画像には対応していません。

## Codexとの接続

ログイン済みのCodex CLIを、非対話モードの `codex exec` で起動します。デスクトップ版Codexの画面を操作する方式ではありません。デスクトップ版が利用できても、指定したCLIのログイン状態や画像生成機能が別途利用可能である必要があります。

自動検出は、補助ファイルがそろったデスクトップ版の標準実行環境（`%LOCALAPPDATA%\OpenAI\Codex\bin`）、PATH上の完全な実行環境、npmの標準インストール先の順でCLIを探します。補助実行用の `.sandbox-bin` は選択しません。このPCでは `codex-cli 0.166.0-alpha.5.1` で文章生成・画像生成・画像入力を確認しています。Codexの更新でパスが変わったときは、設定の「自動検出」を押して保存し直してください。npmの `codex.cmd` / `codex.ps1` ではなく、実体のCLI `codex.exe` を指定します。

APIキーの入力は不要です。既存のChatGPTログインを使用し、利用枠は接続先の契約に従います。ログインが必要な場合は、ご自身でCodex CLIにログインしてください。

入力文・参照画像はCodexへ送信されます。本ツールは既存の認証情報をコピーしません。生成処理では読み取り専用の実行制限を使用し、シェルコマンド、プラグイン、フック、Web検索を無効にします。画像生成にはCodex内蔵の画像生成機能を使用します。ユーザーのCodex設定ファイルは読み込まず、モデルはCLIの既定値を使用します。

画像は参考プログラムと同様に、Codexの `generated_images/<thread_id>` から取得します。この保存仕様はCLIの更新で変わる可能性があります。取得できない場合、成功扱いにはせず、エラーを表示します。

## 保存されるファイル

初期の保存先はexeと同じ場所の `data` です。設定画面で選んだ保存先を次回起動時も使用します。生成物の一覧には現在の保存先の内容が表示されます。「設定を初期化」を押すと、`app/settings.json` を空の設定 `{}` にしてアプリを終了します。次回起動時は既定の `data` と自動検出したCodexを使用し、「保存」を押したときだけ設定値を書き込みます。以前の保存先にある生成物はそのまま残ります。

- `image.png`：生成画像（①）
- `prompt.txt`：生成したプロンプト（②・③）
- `reference.png`：送信した参照画像のコピー（③）
- `request.json`：入力内容と実行条件
- `response.txt`：Codexの最終回答
- `status.json`：完了・失敗・中止の状態
- `events.jsonl` / `diagnostic.log`：問題調査用のログ

「保存フォルダーを開く」で、直近の実行結果を確認できます。失敗や中止の場合も、調査のため入力とログは残します。これらには入力内容が含まれるため、共有する際は内容を確認してください。

## 中止とエラー

「中止」で生成を止められます。画面を閉じた場合も実行中の子プロセスを終了します。サーバーで既に処理された分の利用は取り消せません。処理の上限時間は15分です。

- 接続に失敗：設定のCodexパスとCLIのログイン状態を確認してください。
- 画像が取得できない：`response.txt` と `diagnostic.log` を確認してください。CLI側で画像生成が利用できない場合もあります。
- URLを読み込めない：画像を直接表示するURLか、ログイン不要かを確認してください。
- 保存できない：設定で選択したフォルダーに書き込めるか確認してください。
- 設定を読み込めない：設定画面で再設定して保存してください。

## 構成と検証

- `app/Start.ps1`：画面・イベント処理・実行状態の監視
- `app/Main.xaml` / `app/Settings.xaml`：画面定義
- `app/Core.ps1`：設定、画像取り込み、Codex引数・指示文
- `app/Worker.ps1`：バックグラウンドの生成処理
- `app/tests/Test-Core.ps1`：外部AIを呼ばないテスト

開発時の検証コマンド：

```powershell
pwsh.exe -NoProfile -STA -File .\app\tests\Test-Core.ps1
pwsh.exe -NoProfile -STA -File .\app\Start.ps1 -SmokeTest
```

テストは設定の保存、入力検証、引数の保持、ローカル画像・HTTP画像の取り込み、中止、CLI異常終了を確認します。HTTPテストはPC内の一時サーバーを使い、インターネットには接続しません。SmokeTestは画面を短時間表示し、`app/tests/main-preview.png` を出力します。

実接続の確認結果は `app/tests/live-prompt`、`app/tests/live-image`、`app/tests/live-reference` にあります。テスト結果やログは配布版には不要です。
